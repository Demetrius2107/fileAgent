## M1 闭环骨架搭建计划

**前提**：你已安装 JDK 21 并配置好 `JAVA_HOME`；准备好一个 OpenAI 兼容的 API（base-url + api-key + 模型名）。

### 一、初始化工程
1. 在 `F:/PersonalProject-Demetrius/fileAgent` 下创建 `pom.xml`：
   - Spring Boot 3.3.x parent
   - 依赖：spring-boot-starter-web、spring-boot-starter-data-jpa、spring-ai-openai-spring-boot-starter (1.0.x)、H2、springdoc-openapi、lombok
   - Java 21 编译目标
2. 创建主类 `FileAgentApplication.java`
3. 创建 `application.yml`（OpenAI 配置、H2 文件库、存储路径、检索 top-k、向量库 JSON 路径）

### 二、分层骨架（包 com.demetrius.fileagent）
- `config/AiConfig.java`：注册 ChatClient、EmbeddingModel、SimpleVectorStore Bean（持久化到 JSON 文件）
- `config/WebConfig.java`：CORS + Swagger
- `common/result/ApiResult.java`、`common/exception/GlobalExceptionHandler.java`
- `model/entity`：SessionEntity / MessageEntity / DocumentEntity（JPA）
- `model/enums`：ParseStatus / ActionType / MessageType
- `model/dto`：CreateSessionReq、UploadFileResp、ChatReq、ChatResp、ActionDto
- `repo`：三个 JPA Repository

### 三、解析层
- `parser/DocumentParser` 接口：`List<String> parse(Path file, String mime)`
- `parser/TextParser`、`parser/MarkdownParser`（按段落/标题切块，带重叠窗口）
- `parser/ParserRegistry`：按 MIME 路由

### 四、服务层
- `SessionService`：创建/列表会话
- `DocumentService`：上传 → 落本地存储 → sha256 去重 → 登记 document → 调 ParserRegistry → 调 VectorStoreService 建索引 → 更新 parse_status
- `VectorStoreService`：add(blocks, metadata) / search(query, topK)
- `ChatService`：取 prompt → vectorStore 召回 → 用 rag-prompt.st 装配 → ChatClient 调用 → 解析 JSON → 封装 ActionDto(answer/ask_user) → 落 message → 返回 ChatResp

### 五、接口层
- `SessionController`：POST/GET /api/sessions
- `FileController`：POST /api/sessions/{id}/files、GET /api/sessions/{id}/documents
- `ChatController`：POST /api/sessions/{id}/chat

### 六、提示模板
- `resources/prompts/rag-prompt.st`：约束 LLM 输出结构化 JSON 动作（answer / ask_user）

### 七、验证
- 启动应用 → Swagger UI → 建 session → 上传 .md → 提问 → 拿到基于文档的结构化答案 JSON
- 检查 `storage/vectorstore.json` 与 H2 库表数据

### 范围外（后续里程碑）
PDF/Office 解析、SSE 流式、ChatMemory 多轮、export/chart/script/api 动作、沙箱、审计、业务库连接。
