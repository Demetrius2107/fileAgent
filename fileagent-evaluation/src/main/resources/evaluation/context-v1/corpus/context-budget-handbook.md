# 上下文预算手册

## 历史约束

- 需要保留的历史事实必须来自用户或助手消息中明确出现的内容。
- 历史摘要只能压缩已有消息，不得补充消息中没有出现的原因、金额、日期或人员。
- 当前问题优先级高于历史中的临时约定；如果当前问题没有覆盖旧约定，旧约定仍可作为上下文。

## 预算规则

- 单次工具结果最多保留 4000 个字符。
- 单次运行工具结果累计最多保留 12000 个字符。
- 工具预算耗尽后，Agent 必须基于已有证据结束回答，不能继续调用知识库工具。
- 搜索摘要不足时，应先读取文档目录，再读取需要的原文片段。

## 回答规则

- 知识库命中时，回答中的来源格式为 `[来源：文件名]`。
- 知识库没有相关内容时，可以回答通用知识，但必须明确标注“通用知识”，不得伪造知识库来源。
